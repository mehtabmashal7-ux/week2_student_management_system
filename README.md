# 🎓 Student Management System (Python CLI)

A simple Command-Line Student Management System built with Python. This project allows users to manage student records using Object-Oriented Programming (OOP).

---

## 🚀 Features

- ➕ Add Student
- 📋 View All Students
- 🔍 Search Student by ID
- ✏️ Update Student Information
- 🗑️ Delete Student
- ❌ Exit Program
- ⚠️ Exception Handling for Invalid Input
- 🏗️ Built using Python Classes and Objects

---

## 🛠️ Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- Dictionaries
- Loops
- Conditional Statements
- Exception Handling

## ▶️ How to Run

1. Clone this repository:

```bash
git clone https://github.com/mehtabmashal7-ux/week2_student_management_system.git
```

2. Open the project folder.

3. Run the program:

```bash
python student_management.py
```
